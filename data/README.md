# data/

Nothing in this folder is committed (see `.gitignore`).

| folder | what | source |
|---|---|---|
| `nutzungen/` | yearly Nutzungsflächen shapefiles, 2017–2025 | Kanton St. Gallen — **not publishable** |
| `masks/` | grassland purity mask GeoTIFF, built from the above | derived — **not publishable** |
| `gee/<site>/` | Earth Engine exports (trajectories, per-parcel cut series) | Sentinel-2 via GEE |
| `labels/` | hand-labelled cut dates, one JSON per site | hand labels |
| `station/` | MeteoSwiss daily station series | MeteoSchweiz Open Data |
| `synthetic/` | the same layout, generated by `make demo` | `drought.synthetic` |

Real files and synthetic files never share a folder: the synthetic profile
redirects every path to `data/synthetic/` and `output/synthetic/`.
